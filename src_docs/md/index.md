## Key Features at a Glance

- ✨ **60 FPS Full-Resolution Recording** - Retina-quality screen capture
- 🎵 **Multi-source Audio Recording** - System and microphone audio
- 🖱️ **Precision Input Tracking** - Mouse movements and keyboard events in JSON
- ⚡ **Minimal System Impact** - Optimized for performance
- 🎯 **Clean, Minimal UI** - No clutter, just functionality
- 🔧 **Highly Configurable** - Adapt to your workflow
- 📁 **Flexible Output Formats** - Video, audio, and data files
